KEY FEATURES:
═════════════

✅ Automatic Grouping by Order Line
   - Same item on different order lines appears as separate rows
   - Example: test_1_bolt appears twice (Order Line 1 and Order Line 2)

✅ Combined Quantities
   - Order Line 1: test_1_bolt - Total 100 units shipped
   - Order Line 2: test_1_bolt - Total 50 units shipped

✅ Box Breakdown Format
   - Shows exact box configuration
   - "3 box of 30, 2 box of 5" means:
     * 3 boxes containing 30 units each
     * 2 boxes containing 5 units each
     * Total: 90 + 10 = 100 units

✅ Professional Layout
   - Header with shipment details
   - PO number, date, and customer info
   - Summary statistics
   - Signature lines for workflow

✅ Print Ready
   - One-click print functionality
   - Optimized for paper output
   - Professional formatting


DATABASE STORAGE:
═════════════════

Each row in shipment_boxes table represents ONE BOX:

Shipment: SH215601, Item: test_1_bolt, Order Line 1
  Box #1: 30 units, Pack Size 30
  Box #2: 30 units, Pack Size 30
  Box #3: 30 units, Pack Size 30
  Box #4: 5 units, Pack Size 30
  Box #1 (5 units): 5 units, Pack Size 30

Shipment: SH215601, Item: test_1_bolt, Order Line 2
  Box #1: 50 units, Pack Size 50

The packing slip GROUPS these boxes and shows:
  Order Line 1: 3 box of 30, 2 box of 5 = 100 units total
  Order Line 2: 1 box of 50 = 50 units total


WORKFLOW:
═════════

1. User goes to labels-batch.html
2. Expands a shipment (e.g., SH215601)
3. Enters pack sizes for each item
4. Optionally enters pallet number
5. Clicks "🔒 Finalize & Lock" button
6. Backend creates box records in database
7. Success message shows with "View Packing Slip" link
8. User clicks link to open packing-slip.html
9. Packing slip displays with:
   - Professional header
   - All items grouped by order line
   - Box breakdown for each item
10. User can print with "🖨️ Print" button
11. Printed packing slip goes to warehouse team
