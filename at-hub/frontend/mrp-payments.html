MRPeasy PO Payments

Migration tool — phased out once AT-HUB is the system of record.

Payments from MRPeasy's PO export

In MRPeasy: Procurement → Purchase orders → export the list (CSV). It has Paid / Unpaid and the payment status of every PO. For each PO, AT-HUB records the difference between MRPeasy's Paid and what's already recorded here — uploading again never double-counts. The export has no payment dates, so each payment is dated at the PO's invoice due date (never later than today). The file is kept, so a fresh MRPeasy import brings these payments back automatically.
