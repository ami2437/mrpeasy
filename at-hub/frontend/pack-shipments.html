Paste Pack Sizes

Two columns copied from Excel (tab or comma separated, header optional): Item # · Pack Size.

Applies to the selected shipments, or every shipment shown if none are selected. Start a row with a shipment code (e.g. SH-0012) to aim it at one shipment.

The new size becomes the item's default; the previous one is kept in its history (see Pack Sizes).

Paste Pallets

Copied from Excel: Item # · Pallet # · Weight · Dimensions. Weight and dimensions only need to be on one row per pallet.

Applies to the selected shipments, or every shipment shown if none are selected. Start a row with a shipment code to aim it at one shipment.
