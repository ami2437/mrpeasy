File Matcher

Pick the folder that holds the PDFs (subfolders included). Only file names are checked until you attach or read.

Every PDF in the folder (and its subfolders) is checked against customer orders' PO #. A file is attached only when certain: the number is a whole word of the file name, it belongs to exactly one record, and only one file points at that record. Anything else is listed and left alone. Files nothing matched can be read with the AI and turned into draft orders, several at once.
