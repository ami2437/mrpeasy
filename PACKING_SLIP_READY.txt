═════════════════════════════════════════════════════════════════════════════════

A complete professional packing slip system that:

  ✅ Captures shipment finalization data
  ✅ Groups duplicate items by order line
  ✅ Combines quantities and shows box breakdown
  ✅ Displays professional, printable packing slips
  ✅ Stores all data in database for record-keeping
  ✅ One-click print to PDF or paper

🗄️ DATABASE SCHEMA
═════════════════════════════════════════════════════════════════════════════════

ShipmentBox Table (stores one record per box):
  • shipment_code: "SH215601"
  • item_code: "test_1_bolt"
  • po_number: "PO # 123456" ← NEW FIELD
  • order_line: "1"
  • box_number: 1, 2, 3, ...
  • quantity_in_box: 30, 30, 30, 5, 5, 50
  • pack_size: 30, 30, 30, 30, 30, 50
  • finalized_at: timestamp
  • pallet_number: optional


🔌 API ENDPOINTS
═════════════════════════════════════════════════════════════════════════════════

1. POST /api/labels/finalize/{shipment_code}
   • Saves finalization data to database
   • Fetches and stores PO number
   • Creates box records

2. GET /api/packing-slip/{shipment_code}
   • Fetches all boxes from database
   • Groups by order_line
   • Calculates qty_shipped (sum)
   • Generates box_breakdown
   • Returns JSON

📊 KEY ALGORITHM: BOX BREAKDOWN
═════════════════════════════════════════════════════════════════════════════════

Input (6 box records):
  Box 1: 30 units
  Box 2: 30 units
  Box 3: 30 units
  Box 4: 5 units
  Box 5: 5 units
  Box 6: 50 units

Processing:
  Group by quantity_in_box:
    30 units → 3 boxes
    5 units → 2 boxes
    50 units → 1 box
  
  Sort by quantity (descending)
  Format as string

Output: "3 box of 30, 2 box of 5, 1 box of 50"

Result: Much more readable for warehouse staff!
